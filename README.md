## 자가 테스트 표

2026년 기준 기대 결과입니다. 실제 결과는 브라우저 콘솔에서 각 호출을 실행한 뒤 기록합니다.

| 번호 | 호출 | 기대 결과 | 실제 결과 |
|---|---|---|---|
| 1 | `formatNumber("1234567")` | `'1,234,567'` | 확인 전 |
| 2 | `average(movies).toFixed(1)` | `'7.4'` | 확인 전 |
| 3 | `best(movies).title` | `'오디세이'` | 확인 전 |
| 4 | `sortBy(movies, "rating", true)[0].title` | `'오디세이'` | 확인 전 |
| 5 | `filterByRating(movies, 8).length` | `2` | 확인 전 |
| 6 | `search(movies, " 타짜 ").length` | `2` | 확인 전 |
| 7 | `yearsSince("2014-11-06")` | `12` | 확인 전 |
| 8 | 4번 실행 뒤 `movies[0].title` | `'타짜'` | 확인 전 |

평점 합계는 74.4이고, 10편의 평균은 7.44입니다. 소수 첫째 자리로 표시하면 7.4입니다.

최고 평점은 오디세이와 실낙원이 모두 8점입니다. best는 `>`로 비교하므로 원본 배열에서 앞에 있는 오디세이를 반환합니다.

검색어의 앞뒤 공백을 제거하면 "타짜"가 되며, 타짜와 타짜: 벨제붑의 노래가 검색됩니다.
